# 💱 Currency Converter

A simple and responsive Currency Converter built with **React**, **Vite**, and **Tailwind CSS**. It fetches real-time exchange rates from the Currency API and allows users to convert currencies instantly.

---

## 🚀 Features

- 🌍 Convert between multiple international currencies
- 🔄 Swap currencies with a single click
- ⚡ Real-time exchange rates
- 📱 Responsive and clean UI
- 🎨 Built using Tailwind CSS
- ⚛️ Custom React Hook for fetching currency data

---

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- Currency API

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Arhan213/currency-converter.git
```

### Navigate to project directory

```bash
cd currency-converter
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

The application will run at:

```
http://localhost:5173
